# Public research notes

Use this folder for cross-task synthesis, experiment protocols and presentation-ready explanations. The shared paper catalog remains in `platform/data/literature.csv`; do not duplicate its rows or edit generated `platform/site/data/literature.json` here.

Public notes must identify whether a number is from a published paper, a verified run in this repository, or a proposed experiment. Keep internal Obsidian notes and private paths in the private vault. For a new run, start from [the experiment record template](EXPERIMENT_RECORD.md) and store the completed record beside its DPO/GRPO run, not as an orphan note here.

The [repository layout](REPOSITORY_LAYOUT.md) records how task code, results and websites fit together.
