# Reward 构造

## 输入与输出

每个任务的评分项由生成前的 `task_id`、歌词、角色计划与是否允许重叠决定。先保留最终 mix，优先用渲染对应的原生 vocal stem 提声纹。仅有 mix 时固定一个分离器版本，同时检查最终 mix 的人声是否足够可听。每项输出 `raw_value`、`value_01`、`status`、`valid_seconds`、`evidence_intervals`、`reason` 和 `scorer_version`。训练、排序和诊断分别记录各分量。

## 第一批能做的分数

| 分数 | 怎么算 | 主要用途 |
| --- | --- | --- |
| `music` | 有效音乐时长 ÷ 计划音乐时长，截断在 0–1。活动阈值从正常音乐、静音、噪声对照标定，合法尾音/静音边界给容差。 | 所有任务，发现空音频和提前结束 |
| `quality` | 团队现用音乐质量 reward，经开发集冻结映射到 0–1。盲听另记伴奏、混音与表现力。 | 原 reward 对照与质量守门 |
| `vocal_presence` | 在有歌词的段落，按歌词对齐检查可听主唱，并记录有声覆盖与缺失区间。允许前奏、间奏、尾奏。在 mix 上查低声量和仅开头唱几秒。 | 所有演唱任务，发现无唱、弱唱、断唱 |
| `lyrics` | 用验证过的歌词对齐或歌声 ASR 检查有序歌词行覆盖。`已匹配的必唱行 / 必唱行数`。插入或重复行另记，语言分别审计。 | 漏唱、唱错段、重复同一句 |
| `no_vocals` | `1 − 确认可听人声累计时长/有效音乐时长`。同时记录最长连续人声事件以及 lead/backing/spoken/ad-lib 标签。 | 纯音乐；用合唱音色合成器、管乐及极低漏唱作校准 |
| `voice_prompt` | 有声线要求时用人听校准过的角色描述分类分数，保留不确定项。 | 男/女声线等 prompt 遵循；单人内部身份分独立计算 |

### 独唱身份分，四个版本做离线对照

从原时间轴取 3 秒窗、1.5 秒步长，按可靠的单人演唱窗口取归一化 embedding \(e_i\)。窗口应主要含可听人声，跨角色边界或显著分离伪影的窗标为不可用。第一版用 [歌声专用 encoder](https://github.com/SonyCSLParis/ssl-singer-identity)。在验证集报告所有 scorer 的不可评比例、误报和得分方向。

| ID | 计算 | 优先检验的情况 |
| --- | --- | --- |
| `id_mean` | 比较所有不重叠窗对的 cosine，取均值 | 全曲基线，对照平均值是否掩盖短漂移 |
| `id_tail` | 同一预期角色内，仅比较中心间隔 ≥6 秒的窗对，取 cosine 的第 10 百分位 | 候选主训练项，抓中途替换和跨段漂移 |
| `id_anchor` | 取与其余窗平均 cosine 最高的实际窗口作 medoid。计算各窗到 medoid 的 cosine，取低分位 | 突变定位、短段变声；用长时间换声样本检查锚点被污染的情况 |
| `id_run` | 沿时轴找连续低锚点相似度的可靠窗口。以窗中心的覆盖区间并集计秒，`1 − 异常秒数 / 可靠有声秒数`。间断、合法角色边界切开事件。 | 区分瞬时伪影与持续变声，并返回可听测的时段 |

启动参数为至少 6 个可靠窗口、覆盖至少两个预期演唱段、`id_tail` 至少 6 个合格窗对。`id_run` 的相似度阈值和最短持续时间由开发集音频确定。保留正常真假声、气声、力度、音高变化来测误罚，保留不同漂移长度来测漏报。用开发集冻结 score→[0,1] 映射，例如按开发集第 5/95 百分位做截断线性映射。记录饱和、平局和分离伪影。四项离线比较后选一个训练项。有合法参考声样的任务可另测窗口对参考声纹的相似度，当前无参考独唱保持同曲内比较。

### 从轮唱扩展到合唱

| 分数 | 怎么算 | 使用条件 |
| --- | --- | --- |
| `role_fit` | 用歌词对齐确定段落；对预测身份簇做**全曲一次**的角色匹配，按计划有声时长比较预期与实际。计错角色率、边界外切换率，边界容差由对齐误差确定。 | A 与 B 的角色由歌词/段落计划给出。若声线可辨别，另外校验指定声线。 |
| `role_cover` | 对每个角色算其计划段落内的实际覆盖，再取两者最小值。 | 避免第二个人仅唱一下也得高分 |
| `two_ids` | 用可变身份数的聚类或经验证的 diariser，判断两位身份都有充分时长，各自可信；记录漏人和第三身份。 | 阈值用一人自和声、双人同音域、逐段变声做校准 |
| `role_id` | 每个角色分别计算跨段身份一致性；按角色等权并报告最差角色。A1→A2 单独记录。 | A–B–A 对照 A–B–C；B 若只有一段，只能量段内稳定性 |
| `overlap` | 对已要求两人同时唱的歌词段，估计确有两位可辨身份同时活跃的时长占比。 | 依赖经歌声验证的重叠识别。用 solo anchors（A、B 各自独唱段）辅助确认；盲测同人叠录、两人响度互换。 |
| `balance` | 在确认双方同时活跃的区域，计算两条可信角色流的人声响度差和各自可辨覆盖。 | 先做听测诊断；平衡目标随编曲变，合唱评分上线前单独校准 |

## 第一轮训练标量

对演唱任务冻结共同可行门 `F`：有效音乐、主唱可听且歌词覆盖达到开发集阈值时为 1；确认漏唱、静音、短唱后停止等为 0。`C∈[0,1]` 是现有 reward 的冻结映射，`I∈[0,1]` 是唯一选中的身份分。主消融使用同一门及同一 `C`。

- **A 对照** `R_A = F + 0.9*C`。
- **B 新项** 若 `F=1`，`R_B = 1 + 0.9*((1−λ)*C + λ*I)`；若 `F=0`，`R_B = 0.9*C`。开发集先测 `λ=0.10, 0.25, 0.40`，按预定规则锁一个；0.25 是启动值。
- 记录未经门控的现用 reward 作为离线对照。每个组里，确认完成的样本分数高于确认失败的样本。仪器判定不确定时先交由标注/校准，避免把判定噪声变成硬门。
- 任务扩展的初始档内配方供开发集比较：纯音乐 `0.5*quality + 0.5*no_vocals`，门用有效音乐与确认为纯音乐；轮唱 `0.30*quality + 0.20*lyrics + 0.20*role_fit + 0.15*role_cover + 0.15*role_id`，门加入两位角色有足够覆盖。合唱通过专项校准后再试 `0.25*quality + 0.20*lyrics + 0.20*role_fit + 0.20*overlap + 0.15*role_id`。每个任务用冻结的适用项和版本。

`constraint_violation` 是有效的生成失败，留在原组。`not_applicable` 由输入任务确定。应当评分却缺证据用 `unscorable`，例如要求独唱但分离质量不足。已完成样本的必要分量不可评，以及重试同一输入仍失败的 `infrastructure_error`，都延后或剔除完整组并报告覆盖率。各候选的固定权重保持一致。近似平局阈值由听测和重复性估计给出；如果使用该策略，两组实验采用同一平局规则，并同时报告受影响的组比例。
