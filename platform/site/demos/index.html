单项 reward 定义、各自的盲点与组合权重

所有分数都对带 S/A/T/B 标签的参考 MIDI 计算。单项 GRPO 每次只优化一项；Combined 是加权和，不能保证杜绝 reward hacking。下列盲点来自构造的 MIDI 反例，不等于训练策略必然学会利用它们。

Reward定义单独优化时的典型盲点Combined 权重
Onset按声部和音高一对一匹配，起点容差 50 ms 的宏平均 F1。音符可以很短，起音准但持续时长不对。0.25
Onset + offset再要求终点误差不超过 max(50 ms, 参考音长 20%) 的完整音符宏平均 F1。可能只保留少量容易匹配的音符，漏掉弱声部。0.25
Frame10 ms 网格上的逐声部音高占用宏平均 F1。长音被拆成碎音符时，帧占用仍可能较高。0.15
Coverage0.5 秒窗口内，哪些声部正在发声的 active-voice F1。同一声部内乱加八度音，声部覆盖仍不变。0.10
Continuity1 − 持续音碎裂率。安静或空白输出也能取得很高连续性分数。0.05

已完成的 Combined 实验仍含两项此处不再单独展示的奖励，各占 0.10；保留原始权重和结果，不将其追认为五项奖励的新实验。

指标定义、n/a 与测试协议

SongBench：Vocal、Instrumental、Melody、Structure、Arrangement、Mixing、Musicality 七维均值（0–10），另列 Musicality。SongEval：Coherence、Musicality、Memorability、Clarity、Naturalness 五维均值（1–5），另列 Musicality。两者不是同一个 reward。

AudioBox PQ 衡量制作质量；MuQ-MuLan / AllMusicCaps 衡量音频与风格文本相似度，不混入歌词。Q3O 是冻结属性加权的提示控制（0–5），不是歌曲质量；WSB 可算但需 80 GB GPU，目前未提交此 scorer。PER 为总 phoneme edits / 总 reference phonemes；越低越好，保留漏唱歌词和截断，不裁剪 reference 来提高分数。

PER / MuLan / AllMusicCaps 使用官方冻结 worker 与权重。SongBench 保留原模型、权重、FP32 MuQ 前处理，但官方 cu126 环境不支持 5090；本站采用已记录哈希的 Torch 2.9.1+cu128 兼容运行时，不宣称通过原环境复现。SongEval / AudioBox 是单独版本固定、留有模型哈希的补充实现。客观表评分输入使用已绑定哈希的 192 kbps MP3，与官方 WSB 编码协议一致；它和训练 reward 的 WAV / PCM24-FLAC 口径不同。部分集只显示覆盖度，不显示貌似完整的均分。

WSB 七条可用 YuE2 臂（冻结 baseline + 六个正式 final-step 270 checkpoint）已进入顺序 evaluation 队列；CMI-Pref 同样评估全部 121 条。Muse 新臂仍等待训练，未借用旧小 LR / Mock 的结果。Test 不选择 LR / checkpoint，不新增训练，不改变原有 270/30 split。

共同报告规则 · condition split / candidate budget / long-form test
          
Protocol固定内容为什么

            
先划来源，再取片段按歌词 / prompt / reference recording 分组；同歌候选、投票、切片不得跨 split。官方 test 在 train/valid 前隔离。防止 469 票被误当 469 首歌，或同一参考音频、歌词泄漏到 test。

            
模型使用 native 输入投影固定来源三模态元数据；对 text+lyrics、audio+lyrics、三模态分层报告，列 missing-modality mask 与 prompt adapter。公平比较是同条件来源和明确接口差异，不是假装所有模型都支持三模态联合。

            
训练 / 验证 / test 三条口径online reward + reference-policy KL；固定 valid conditions 选 LR/checkpoint；test 评估已固定的 final-step 270 臂，失败样本也计入，不能据此重新调参。训练曲线有采样波动；scorer 自评和 3 条精选 demo 不能证明泛化。

            
候选预算一致固定种子数量、temperature、top-p、planning、codec 与 best-of-N 选择器；另列 reranking 成本。WSB best-of-2 / best-of-8 不是单 seed baseline；不能只挑好的输出比较。

            
长片段与整歌另测本站正式试听约 64 秒；训练/validation 仍是 600-token 短片段。整歌 test 使用完整 planning、benchmark legacy VAE、9000-token 上限；记录实际时长及截断。不能把延长 inference 当成已经验证长歌 RL；缺失歌词后半段、重复与结构退化须单列。

            
reward 与独立判断分开审美五轴、歌词 PER、style similarity、信号失败率和 blind A/B 各自报告。训练 reward 的原始格式不变；整歌 test 按官方 WSB 的 192 kbps MP3 编码评分，分别绑定 lossless 原件和评分 MP3 哈希。不把 FAD 当逐样本 reward，不把同源 SongEval / MuseCritic cross-score 当完全独立真值。

Training objectives · 六臂消融

        
六臂从相同冻结 LaDA-Band 起点训练。设 B 为原 Madmom Beat-v2 F1，C 为 40 ms 帧中 RMS > 0.01 的比例，Q 为峰值/削波/频谱平坦度惩罚。各臂 reward 量表不同，不可直接比较曲线高度。

        
Experiment实际目标单独优化的盲点 / 约束的局限

          
Coverage onlyC持续发声即可升分；不看拍点、和声和音质，接近满分后丧失区分度。

          
Beat-v2 onlyB稀疏但对齐的敲击可骗到高分；不约束连续伴奏、响度或音色。

          
Proxy blend · no Beat-v20.45 C + 0.35 起音能量相似度 + 0.20 频带占用 − Q多了起音和频带代理，但没有实际 Beat-v2，也没有经验证的 Richness；仍可发生响度漂移。

          
Beat-v2 + Coverage guard0.65 B × min(1, C/0.4) + 0.35 min(1, C/0.7) − Q − L − FB 是实际 Beat-v2；L 惩罚伴奏/人声 RMS 比超出 −18 至 −3 dB，F 惩罚过高平坦度。不保证杜绝 reward hacking。

          
Beat-v5 only前序项目 Beat-v5 onset-grid score；附 confidence / abstention构造 click 仍可高分；confidence 不能判断和声或编曲。

          
Richness-v0 proxy音调性门控 ×（0.60 频段活动 + 0.25 时间变化 + 0.15 活动率）− Q − L频段活动不是乐器数量；走音叠层也可高分。此代理没有主观丰富度验证。

        

        
在线训练只看前 6 秒；固定 12 秒回放在下方统一复算，逐 checkpoint 的目标值与试听列在主实验页。主实验页的 KL 曲线是更新前采样动作上的近似估计，以冻结底座为参考，损失系数 β = 0.01；大尖峰需单独检查。

Reward map · 论文指标与本站训练目标

          
PawCT 使用 part-aware 的 onset / offset / frame 与 part-presence 目标；多 F0 和声部分配工作测量的是不同终点。本站的 GRPO reward 是参考 SATB MIDI 上的七项加权分数；下面的五个单项训练臂与受控反例均是本站实测或诊断，不是论文直接报告的 GRPO 结果。

          
信号文献/实现连接适合的角色单项优化风险

            
SATB onset + complete-note F1PawCT 的 part-aware note 评价；本站 一对一匹配主 reward / 封存测试；起点 50 ms，offset max(50 ms, 20% 音长)只看 onset 会缩短音；只看完整音符可能偏向易音，牺牲弱声部

            
Frame + activity / part presencemulti-F0 与 PawCT 的帧/声部目标辅助连续性及活跃声部 coverage；只对参考活跃窗口比较frame 看不见切碎长音，coverage 看不见声部内多余八度

            
Per-voice floor / precision / fragmentation本站 组合 reward 与反例审计约束漏 Bass、过填与短碎音precision-only 可删难音；continuity-only 在静音时也可能高分

            
F0 accuracy / voice assignmentCuesta multi-F0 + VoAS两阶段诊断或辅助一致性实验；本站尚未作为 GRPO rewardF0 正确不保证 note segmentation，交换 S/A 也可能被 part-agnostic 匹配漏报

          

          
组合权重与评估边界
本站已跑的加权目标：onset .25、onset+offset .25、frame .15、active-voice .10、最弱声部完整音符 .10、完整音符 precision .10、1−fragmentation .05。逐项量表都在 [0, 1]；不能据此推断组合必然不被利用。报告四声部宏平均、逐部 recall、frame / onset / onset+offset F1、有效更新、KL 与音符数；同一输入配对试听作主观核查。
