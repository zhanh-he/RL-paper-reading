# Experiment demos

The [experiment hub](index.html) is a static, source-backed presentation page. `results.json` is generated by `platform/scripts/build-experiment-demo.mjs` from the aggregate GRPO and MIDI-audit receipts; do not edit it by hand. The two WAVs in `audio/` are a synthetic original guide and one ACE-Step inference result, not a GRPO before/after pair.

Future per-run demos should show a fixed input, matched baseline and post-training output, evaluation definitions and a link to the experiment record. Only redistribute audio/MIDI/media with clear rights, and never put private datasets or checkpoints in GitHub Pages.
