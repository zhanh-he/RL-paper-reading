# Experiment demos

The [experiment hub](index.html) is a static, source-backed presentation page.
`results.json` is generated by `platform/scripts/build-experiment-demo.mjs`
from aggregate receipts; do not edit it by hand. YuE2 and Muse each have an
original-lyrics, same-seed, on-policy one-step SongEval-GRPO before/after audio
pair with replay controls. They are small engineering pilots, not long-run or
human-quality results. The separate ACE-Step WAVs are base-model inference,
not GRPO or isolated accompaniment.

Future per-run demos should show a fixed input, matched baseline and post-training output, evaluation definitions and a link to the experiment record. Only redistribute audio/MIDI/media with clear rights, and never put private datasets or checkpoints in GitHub Pages.
