# Experiment demos

Create `platform/site/demos/<task>/<run-id>/index.html` only for a verified run with an accompanying `rl/<method>/<run-id>/README.md`. A demo should show the fixed input, baseline and post-training output under matched settings, evaluation definitions and a link to the record. Use only audio/MIDI/media that can legally be redistributed. Multiple demos can have independent pages and assets; avoid copying large model or dataset files into GitHub Pages.
