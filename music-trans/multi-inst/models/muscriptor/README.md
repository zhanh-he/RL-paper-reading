# MuScriptor

Upstream: [paper](https://arxiv.org/abs/2607.08168), [code](https://github.com/muscriptor/muscriptor), [model organization](https://huggingface.co/MuScriptor). The released checkpoints are gated and noncommercial; this directory never mirrors weights. An approved medium checkpoint is available in the lab's existing offline cache for local training, whereas a fresh small-model download is still blocked for the current account. The public repository's final checkpoints do not provide a clean pre-RL baseline for reproducing its paper's pre/post comparison.

On 30 Sep 2026, we submitted our original 10.2-second synthetic SATB example to the [official hosted demo](https://muscriptor.kyutai.org/) and downloaded its MIDI and SoundFont-rendered audio. The [receipt](muscriptor_receipt.json) and [demo](https://zhanh-he.github.io/RL-paper-reading/demos/#choral) show 16 notes on one acoustic-piano track, with pitch-only 50ms onset F1 0.667 and onset+offset F1 0.500 for this single example. The online model did not provide SATB labels, so there is no track-aware score. This is an inference baseline, not a GRPO result or held-out benchmark.

A later audit found an **existing, previously validated MuScriptor-medium checkpoint** in the team's older offline benchmark cache (306.5M parameters; weights SHA-256 `ac80adbdf85d87231735fd948af7013441c0afced316c4e9067fd5d8a7fb97ec`). It loaded successfully without a new hub request. Small remains inaccessible to this account; medium is available for local academic experiments. We do not publish or mirror either checkpoint.

**GRPO feasibility:** the released decoder-only model exposes sampled token generation and a differentiable `forward(sequence, condition_tensors)` returning next-token logits. The [medium token-head pilot](../../rl/grpo/muscriptor_grpo_smoke.py) implements grouped sampled MIDI rollouts, reference-backed pitch-only rewards, replayed token log-probabilities, clipped policy ratio and KL to the frozen initial head while updating only the output projection. All 50 requested steps made optimizer updates; the saved head differs from the original checkpoint. On its one 5 s training example, onset F1 changed `0.179 -> 0.292` and complete-note F1 `0.123 -> 0.213`. A separately decoded [anonymous 8-song audit](../../rl/grpo/runs/2026-09-30-muscriptor-medium-smoke/disjoint8.json) changed first-5-second pitch-only macro onset F1 `0.043 -> 0.109` and complete-note F1 `0.037 -> 0.103`. This is exploratory: the training song was selected from an older benchmark, the audit was added after training, there is one seed, no full-song run and no SATB/instrument-aware score. The official package does not provide this trainer out of the box; the current result does **not** reproduce MuScriptor's paper or establish a robust quality gain.
