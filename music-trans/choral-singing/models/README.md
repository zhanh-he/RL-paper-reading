# Choral model adapters

The [research map](../research/README.md#models) separates direct SATB event transcription, merged choral notes, general multitrack transcription and F0/voice-assignment stages. Create a model subfolder when its code, weights, license and SATB output adapter can be documented publicly. Do not copy private checkpoints or training data here; a general instrument-labelled track is not automatically a choir part.
