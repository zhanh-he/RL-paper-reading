# YuE2

Upstream: [official YuE repository](https://github.com/multimodal-art-projection/YuE) and [YuE2-3B model card](https://huggingface.co/m-a-p/YuE2-3B). The public model weights are noncommercial; obtain the needed permission before using company infrastructure for product work. Its ABC/semantic autoregressive stages and acoustic flow/VAE stages have different trainability, so a future post-training run must say which stage changes and which remain frozen. This folder does not contain weights or a GRPO trainer.
