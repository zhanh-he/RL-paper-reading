# Vocal-to-accompaniment post-training

For a validated reward comparison, run beat, coverage and richness **one at a time** from the same starting policy and fixed-vocal inputs before claiming a combined recipe is better. The time-limited LaDA showcase ran a fast combined *proxy* first; its [GRPO record](grpo/README.md) reports measured checkpoints and explicitly treats the single-reward arms as separate follow-ups. [DPO](dpo/README.md) needs same-vocal preference pairs; GRPO-style online updates need same-vocal grouped rollouts. Keep each run's reward version, duration, seeds, compute and independent listening record using the [experiment template](../../../notes/EXPERIMENT_RECORD.md).
