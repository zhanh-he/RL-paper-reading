# AnyAccomp

Upstream: [official code](https://github.com/AmphionTeam/AnyAccomp) and [weights](https://huggingface.co/amphion/anyaccomp). This candidate generates accompaniment conditioned on vocal or solo-instrument melody. Its accompaniment-only output should not be compared with a full-mix model until both are evaluated against the same fixed original vocal. Check the checkpoint license and training pathway before an RL run.
