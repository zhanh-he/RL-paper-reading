# Update requests

Create one Markdown file per new request. Choose [literature](literature/README.md) for paper/catalog changes or [new methods](new-methods/README.md) for an optimizer, reward or experiment proposal. Name it `YYYY-MM-DD-author-short-topic.md`; include source links and the author's own rating or judgment where relevant. A maintainer moves a completed request to [archive](archive/README.md) with its original text and a processing receipt.

The root `Update_request_zhanh.txt`, `Update_request_felix.txt` and `Update_request_hanyu.txt` are legacy inputs. They and `Done_UPD_request/` remain untouched so pending requests are not accidentally marked done. New work goes in this folder; don't add more material to the legacy files.
