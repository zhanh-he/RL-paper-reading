Choose the catalog first, then edit your TXT through GitHub's web editor. No installation or GitHub App is needed.

Include the paper/link, requested change, contributor name and any explicit rating. For work spanning both fields, say which catalog should own the record and link the related request; do not create duplicate entries.

New completed requests go to `rl/done_requests/` or `amt/done_requests/` with an AWST timestamp and a processing receipt. The original TXT is retained verbatim in the archive, and the intake template is reset. Historical archives under [done_requests](done_requests/) remain unchanged. The three old top-level TXT files are compatibility inboxes, not the recommended entry points.
